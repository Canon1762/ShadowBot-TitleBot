# 影刀 RPA：Gemini 商品标题提取器

专用于批量导出 Gemini 提示词结尾附带的商品标题至 WPS 表格，适用于影刀 RPA（6.3.22以上版本）。

### 用法：
1. 在影刀 6.3.22 的可视化流程里，搜索“插入代码段(Python)”；
2. 把本文件从第一行到最后一行整段粘贴进去；
3. 只修改下面“只改这里”的 10 个设置；
4. 先令 MAX_ITEMS = 1 测试一行，成功后再改成正式数量。

<mark>这段代码不调用任何 AI API，不使用 OCR，不依赖屏幕坐标。</mark>

### ==================== 只改这里 ====================
```
TARGET_COL = "B"                   # 目标列，例如 B

START_ROW = 2                      # 第一个绿色行；如果第一个绿色行是 86，就填 86

ROW_STEP = 4                       # 每次向下跳几行；你的表是 4

MAX_ITEMS = 10                     # 先填 1 测试；正式批量时填实际条数

SHEET_NAME = ""                    # 留空 = 当前激活的工作表；也可以填 "Sheet1"

GEMINI_URL_KEYWORD = "gemini.google.com"

BROWSER_MODE = "chrome"            # chrome=谷歌浏览器；edge=Edge；cef=影刀浏览器

PAGE_PICK_MODE = "active"          # active=只抓当前选中的网页；latest=多个匹配时取最新打开的网页

READ_MODE = "batch"                # single=每次读最后一条标题；batch=一次读最后回复里的所有标题

WAIT_BEFORE_READ_SECONDS = 0       # Gemini 还在生成时，可以改成 1 或 2

SAVE_AFTER_RUN = True              # True=跑完后自动保存 WPS；第一次测试保持 False
```

### 一、实际业务流程

Gemini 中已经生成了一批内容，每条内容中都有一个明确的“商品标题”。

我需要把 Gemini 当前商品标题复制出来，然后写入 WPS 表格。

WPS 表格不是每一行都人工填写。

表格结构如下：

第1条：

第2行 = 绿色背景 = 真正需要写入标题的单元格

第3行 = 白色背景 = 自动等于第2行

第4行 = 白色背景 = 自动等于第3行

第5行 = 白色背景 = 自动等于第4行

第2条：

第6行 = 绿色背景 = 真正需要写入标题的单元格

第7行 = 白色背景

第8行 = 白色背景

第9行 = 白色背景

所以真正需要操作的行是：

2 → 6 → 10 → 14 → 18 → 22……

也就是说，每完成一条，下一次操作行号 = 当前行号 + 4。

### 二、WPS 中实际需要替换的内容

WPS 当前绿色单元格中的原始文字类似：

自粘墙纸 PVC 可移除，易安装不留残胶，，客厅卧室厨房家具翻新装饰墙贴。

这里不是按照英文逗号分字段。

我要找的是两个【紧挨着的中文逗号“，”】。

真正需要替换的是：

第一个中文逗号

和

第二个中文逗号

之间的全部文字。

例如原文：

自粘墙纸 PVC 可移除，易安装不留残胶，，客厅卧室厨房家具翻新装饰墙贴。

Gemini 获取的新商品标题：

法式复古飞鸟与百合花枝，优雅沉静莫兰迪绿水彩氛围

最终结果必须是：

自粘墙纸 PVC 可移除，易安装不留残胶，法式复古飞鸟与百合花枝，优雅沉静莫兰迪绿水彩氛围，客厅卧室厨房家具翻新装饰墙贴。

**要求：**
1. 第一个中文逗号之前的内容完全不变。
2. 第二个中文逗号以及其后的内容完全不变。
3. 只替换两个中文逗号之间的内容。
4. 必须使用中文逗号“，”作为判断依据。
5. 不能误用英文逗号 ","。
6. 如果当前单元格找不到至少两个中文逗号，必须报错并停止，不得继续执行。
7. 新标题本身如果包含中文逗号，要考虑如何避免错误截断，请给出安全处理方案。
